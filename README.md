# AI Translate Machine

A command-line tool that translates text using Claude AI.

## Installation

    git clone https://github.com/DavidXingWei/AI-translate-machine.git
    cd AI-translate-machine
    pip install anthropic python-dotenv
    cp .env.example .env

Then edit .env and add your Anthropic API key.

## Usage

    python translate.py "Hello, how are you?"

## Tech Stack

- Python 3.12
- Anthropic Claude API
- python-dotenv
